Introduction to Data Representation in Computing

A beginner-friendly guide to how computers represent and process information.

1. What is Data Representation?

Definition: Data representation is the method of converting information into a format that a computer can understand, process, store, and communicate.

Humans use languages, symbols, and decimal numbers to communicate. Computers, however, work internally with binary digits: 0 and 1.

Examples:
  • The character A is represented in standard ASCII as 01000001.
  • The decimal number 10 is represented in binary as 1010.

In simple words, data representation is the process of expressing information in a computer-readable form.

2. Why is Data Representation Important?

  1. It allows computers to understand and process information.
  2. It helps store data in memory and storage devices.
  3. It enables communication and data exchange between computers.
  4. It supports mathematical and logical operations.
  5. It makes it possible to represent text, images, audio, and video digitally.

4. Number Systems in Computing

A number system is a way of representing numbers using a set of digits or symbols. The four commonly used number systems are:

1. Binary — Base 2 Digits: 0 and 1

Example: (1010)₂ = (10)₁₀

2. Decimal — Base 10 Digits: 0 to 9

Example: (25)₁₀

3. Octal — Base 8 Digits: 0 to 7

Example: (17)₈ = (15)₁₀

4. Hexadecimal — Base 16 Digits: 0 to 9 and A to F

Example: (A)₁₆ = (10)₁₀

A. Binary Number System

  • Base is 2.
  • It uses only 0 and 1.
  • It is the fundamental number system used internally by digital computers.

B. Decimal Number System

  • Base is 10.
  • It uses digits from 0 to 9.
  • It is the number system commonly used in everyday life.

C. Octal Number System

  • Base is 8.
  • It uses digits from 0 to 7.
  • Each octal digit corresponds to three binary bits.

D. Hexadecimal Number System

  • Base is 16.
  • It uses digits 0 to 9 and letters A to F.
  • A = 10, B = 11, C = 12, D = 13, E = 14, and F = 15.
  • Each hexadecimal digit corresponds to four binary bits.

5. Types of Data Representation

1. Numeric Data

Numeric data represents numbers. It includes integers (whole numbers) and floating-point values (numbers with fractional parts).

Examples: 100, 25.5, -10.

2. Character and Text Data

Text data represents letters, digits, punctuation marks, and other symbols. Computers use character encoding standards such as ASCII and Unicode.

Examples: A, Hello, @.

3. Image Data

Digital images are commonly made up of small units called pixels. Each pixel stores information about color and brightness.

4. Audio Data

Digital audio is commonly created by sampling an analog sound signal and converting the samples into digital values. Quantization assigns each sample a representable digital value.

5. Video Data

Digital video is usually represented as a sequence of images called frames, often combined with digital audio.

6. Character Encoding

Definition: Character encoding is a system that assigns numeric values to characters so computers can store, process, and exchange text.
EncodingDescription
ASCIIStandard ASCII represents 128 characters using 7 bits.
Extended ASCIIA general term often used for 8-bit character encodings; there are multiple variants.
UnicodeA universal character standard that assigns code points to characters from writing systems around the world.
UTF-8A variable-length Unicode encoding that uses 1 to 4 bytes per code point.
Example: Capital letter A
  • Decimal (ASCII): 65
  • Binary (8-bit form): 01000001
  • Hexadecimal: 41

7. Real-Life Example of Data Representation

Imagine typing Hello 123 on a computer:

  • The letters are stored using a character encoding such as UTF-8.
  • The digits are stored as text characters if they are part of the message. If used in a calculation, they may be represented as numeric values.
  • Photographs are represented as pixel data.
  • Recorded sound is represented as digital audio samples.
  • Movies are represented using video frames, usually with audio.

All of these forms of information are ultimately stored and processed as binary data inside a computer.

8. Advantages of Data Representation

  1. Makes information understandable to computer systems.
  2. Supports organized and efficient data storage.
  3. Enables computers to process different types of information.
  4. Supports reliable data communication.
  5. Allows digital representation of multimedia such as images, audio, and video.

9. Quick Revision

  • Computers use binary digits (0 and 1) internally.
  • A bit is the smallest basic unit of digital data.
  • One byte contains 8 bits.
  • The four common number systems are binary, decimal, octal, and hexadecimal.
  • ASCII and Unicode are used to represent text.
  • Images use pixels; digital audio uses samples; digital video uses frames.
